# Gameboxd Web

> Plataforma web para catalogar, avaliar, organizar e compartilhar experiências sobre jogos.

## Sobre o projeto

Gameboxd é uma plataforma web inspirada em serviços como Letterboxd e Backloggd, desenvolvida para permitir que usuários cataloguem jogos, publiquem avaliações, organizem suas bibliotecas e compartilhem experiências com outros jogadores.

Além das funcionalidades sociais tradicionais, a plataforma contará com um feed dedicado ao compartilhamento de screenshots, permitindo a descoberta de imagens relacionadas aos jogos da comunidade.

Este projeto tem como o principal objetivo servir de portfólio, sendo desenvolvido com foco no aprendizado e aplicação de conceitos modernos de Engenharia de Software, Arquitetura de Software, Backend e Frontend.
